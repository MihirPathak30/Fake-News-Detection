About the System

A complete machine learning project built with Python 3.12, Flask, scikit-learn, pandas, nltk, and joblib.

Training Pipeline

The project merges True.csv and Fake.csv, preprocesses article content, extracts TF-IDF features, and trains a Logistic Regression classifier.

Prediction Modes

Users can paste news content directly or upload a TXT file. The application returns a label, confidence, probability split, word count, and timing.

Reliability

Friendly error messages cover missing models, missing datasets, unsupported uploads, empty input, and general server errors to avoid crashes.

Workflow Overview

  1. Run setup_project.bat to create the virtual environment, install dependencies, download NLTK resources, and train the model.
  2. Run run_project.bat to verify artifacts, launch Flask, and open the browser automatically.
  3. Use the Prediction page to evaluate custom news text or TXT files.
